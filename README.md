# GMARCH文系数学 必修解法パターン200選 Webアプリ

GMARCHレベルの文系数学必修解法パターン（全200問）を2段階（トリガー想起 ➔ 模範解答確認）で演習できるWebアプリケーションです。

## 特長・機能
- **単元別演習モード**: 指定した単元・分野の問題を順番に学習
- **ランダム演習モード**: 全問題からランダムに出題
- **やり直し演習（ストック機能）**: 「覚えていない」と判定した問題を自動記録・復習
- **Excelファイルの読み込み**: カスタムのExcel（.xlsx）問題を読み込んで演習可能
- **GitHub Pages対応**: ブラウザのみで完結（サーバーレス）

## 使い方（GitHub Pagesでの公開手順）
1. 本リポジトリの全ファイルを新しいGitHubリポジトリにアップロード（コミット）します。
2. リポジトリの **Settings** ➔ **Pages** に移動します。
3. **Branch** を `main` に設定し、**Save** をクリックします。
4. 数分後に発行されるURLからアクセスすると、Webアプリとして利用できます。
